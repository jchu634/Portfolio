## Blog drafts

Keep unfinished posts in `blogposts/drafts/` using the same `.tsx` format as
published posts. Drafts appear in the blog index and at `/blog/<filename-without-.tsx>`
when running `pnpm dev`, including navigation and social preview images.
Drafts are excluded from production routes and the sitemap, and Git ignores the
folder's contents. Move a finished post into `blogposts/` to publish it.
